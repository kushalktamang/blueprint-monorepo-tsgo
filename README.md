# Blueprint Monorepo TypeScript Go Starter

A starter blueprint for a Vite+ monorepo with TypeScript and Go server.

## Development

- Check everything is ready:

```bash
vp run ready
```

- Run the tests:

```bash
vp run -r test
```

- Build the monorepo:

```bash
vp run -r build
```

- Run the development server:

```bash
vp run dev
```
